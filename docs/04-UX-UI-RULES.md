# 04 — UX/UI Rules

## Authority

1. Approved Screenshot / Prototype
2. ไฟล์นี้
3. Tabler
4. ADPList
5. Canvas / Handshake
6. Bootstrap 5 Standard

## Direction

Clean Campus Utility:
- ระบบมหาวิทยาลัย
- เรียบ เป็นระบบ น่าเชื่อถือ
- เน้นการใช้งานและข้อมูล
- ไม่เป็น Social Media / Marketplace / AI SaaS

## Forbidden

- Emoji
- Gradient
- Glow
- Glassmorphism
- Blob
- Robot
- Sparkle
- 3D Illustration
- Fake Chart
- Decorative Metrics
- Oversized Hero ใน App
- Card ซ้อน Card เกินจำเป็น
- Pill ทุกองค์ประกอบ
- Floating Action ไร้เหตุผล
- Dead Button/Menu/Route

## Typography

- ภาษาไทย
- Body 14–16px
- ข้อความหลักไม่ต่ำกว่า 13px
- Form มี Label ทุกช่อง
- Validation ภาษาไทย

## Icons

- Bootstrap Icons ชุดเดียว
- ห้าม Emoji แทน Icon
- Icon-only Button ต้องมี Accessible Label

## Student Sidebar

- ภาพรวม
- ค้นหาทักษะ
- ทักษะของฉัน
- คำขอแลกเปลี่ยน
- โปรไฟล์
- ออกจากระบบ

เมนูเพิ่มเมื่อหน้าทำงานจริงเท่านั้น

## Admin Sidebar

- ภาพรวม
- จัดการนักศึกษา
- จัดการทักษะ
- ตรวจสอบคำขอ
- ออกจากระบบ

## Forms / States

ต้องมี:
- Loading
- Success
- Validation Error
- System Error
- Empty State
- Disabled State
- Confirmation

## Responsive

- Target 1366×768, Zoom 100%
- ไม่มี Horizontal Scroll ทั้งหน้า
- Table Scroll ได้เฉพาะ Container
- Mobile ยังทำ Core Flow ได้

## Accessibility

- Label เชื่อม Input
- Focus State มองเห็น
- Modal ใช้ Keyboard/Escape
- สีไม่ใช่ตัวสื่อสถานะเพียงอย่างเดียว
